### How to Set Up on Payhip

1. **Create a product page** for each bundle, using the same title and description format you’ll use for the e‑book.  
2. Upload all files (PDF, MP3, JPG) in a single zip folder per bundle.  
3. Enable **“Digital download”** and set the price as above.  
4. Add a short, enticing description that highlights the bundle perks—e.g., “Unlock the full love story plus exclusive audio and art.”  
5. Optionally, offer a **limited‑time discount** (e.g., 10‑15% off for the first 48 h) to jump‑start sales.  
6. Use Payhip’s **coupon codes** for future promotions (e.g., “LOVE10” for 10 % off on the next purchase).
